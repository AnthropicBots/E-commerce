# frontend/robots.txt
#
# One group per user agent, one Sitemap line. Rewritten for #1446: this file
# previously held two complete copies of itself, so Googlebot had two groups
# and three Sitemap lines pointed at two different hosts. A crawler applies the
# first group that matches its name and ignores every later one, which made
# half the file unreachable and left it unclear which half was authoritative.
#
# The disallow list below and the EXCLUDED set in scripts/generate-sitemap.js
# are the same list. backend/tests/seoArtifacts.test.js asserts that -- a page
# disallowed here must not be submitted for indexing there.
#
# Note that Disallow and noindex do different jobs. Disallow stops a crawler
# fetching the page; it does not stop the URL being indexed from links
# elsewhere. The private pages below also carry an X-Robots-Tag: noindex header
# from frontend/vercel.json, which only a crawler that fetches them can see.
